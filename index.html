      Importa

      Sincronizzazione GitHub

      Salva il diario in un file di un repository GitHub, così non dipende dal telefono. Usa un repository privato: il sito pubblicato è pubblico, il diario contiene dolori, sonno e sensazioni. Il token deve essere "fine-grained", limitato a quel solo repository, permesso Contents: Read and write. Viene tenuto solo su questo dispositivo.
